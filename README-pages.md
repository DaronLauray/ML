# GitHub Pages deployment

This repository contains a static GitHub Pages version of the NBA Winner Predictor interface.

## Files

- index.html — main page
- styles.css — page styling
- app.js — static prediction logic

## Deploying to GitHub Pages

1. Push this repository to GitHub.
2. In GitHub, open the repository settings.
3. Go to Pages.
4. Set the source to the main branch and root folder.
5. Save.

Your app will publish at:

https://daronlauray.github.io/ML/

## Notes

This version is static and does not require a Python/Flask backend.
It estimates a matchup probability from the selected teams and optional date.
